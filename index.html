Utube Auto

운영자 한 사람이 자기 유튜브 채널을 운영하는 데 쓰는 개인용 윈도우 프로그램입니다. 내려받거나 다른 사람이 쓸 수 있도록 배포하지 않습니다.

하는 일

  • 운영자의 채널마다 영상 대본을 쓰고, 숏폼 · 롱폼 영상을 만듭니다.
  • 만든 영상을 운영자의 채널에 비공개로 올리고 공개 시각을 붙입니다(예약 업로드).
  • 공개된 영상에 운영자의 첫 댓글을 달고, 운영자가 정한 규칙대로 댓글을 정리합니다.
  • 운영자 채널의 조회수 · 시청 지속 시간 같은 성과를 읽어, 다음 영상을 정하는 데 씁니다.

구글 계정 사용

운영자가 자기 구글 계정으로 채널마다 로그인해 연결합니다. 프로그램은 다음 두 권한만 청합니다.

  • https://www.googleapis.com/auth/youtube.force-ssl: 운영자 채널에 영상 올리기 · 예약 · 첫 댓글 · 댓글 정리
  • https://www.googleapis.com/auth/yt-analytics.readonly: 운영자 채널의 성과 읽기

구글 사용자 데이터를 어떻게 다루는지는 개인정보처리방침에 적어 두었습니다.

English summary. Utube Auto is a personal Windows desktop application used by a single operator to run their own YouTube channels. It writes scripts, produces videos, uploads them to the operator's own channels as scheduled private uploads, posts the operator's first comment, and reads the operator's channel analytics. It requests only the youtube.force-ssl and yt-analytics.readonly scopes. It is not distributed to other users. See the Privacy Policy.
