Utube Auto 개인정보처리방침

시행일: 2026년 11월 24일 · Utube Auto 소개

1. 이 방침이 다루는 것

Utube Auto 는 운영자 한 사람이 자기 유튜브 채널을 운영하는 데 쓰는 개인용 윈도우 프로그램입니다. 이 방침은 프로그램이 구글 API 로 받는 사용자 데이터를 어떻게 쓰고 보관하는지 적습니다. 프로그램은 다른 사람에게 배포하지 않습니다.

2. 받는 데이터와 권한

  • youtube.force-ssl: 운영자 채널의 정보 · 영상 목록 · 영상 상태 · 댓글. 운영자 채널에 영상을 올리고 예약하며, 첫 댓글을 달고, 운영자가 정한 규칙대로 댓글을 숨깁니다.
  • yt-analytics.readonly: 운영자 채널과 영상의 성과 보고서(조회수 · 시청 지속 시간 · 노출수 · 구독자 증감 등).

3. 쓰는 목적

받은 데이터는 운영자의 채널을 운영하는 데만 씁니다: 영상 올리기와 예약, 첫 댓글과 댓글 정리, 성과를 보고 다음 영상의 소재 · 길이 · 공개 시각을 정하기. 광고나 다른 목적에는 쓰지 않습니다.

4. 저장과 보호

  • 데이터는 운영자 PC 안의 프로그램 데이터 폴더에만 저장합니다. 이 프로그램을 위한 별도의 서버는 없습니다.
  • 구글 연결 토큰은 윈도우 사용자 계정의 보호 기능으로 암호화해 저장합니다.

5. 다른 곳으로 보내는 것

  • 구글 사용자 데이터를 팔거나 광고에 쓰거나, 다른 사람에게 넘기지 않습니다.
  • 채널 성과 숫자와 댓글 글은, 운영자가 자기 계정으로 쓰는 AI 도구(Anthropic Claude)에 보내 다음 영상을 정하는 분석에만 씁니다.
  • 영상을 만드는 그림 · 영상 · 목소리 서비스에는 운영자가 쓴 대본과 지시문만 보내고, 구글 사용자 데이터는 보내지 않습니다.

6. 보관 기간과 지우기

데이터는 운영자가 프로그램에서 지우거나 데이터 폴더를 지울 때까지 운영자 PC 에 남습니다. 구글 계정의 접근 권한은 언제든 구글 계정 「타사 앱 및 서비스」에서 거둘 수 있고, 거두면 프로그램은 더 이상 데이터를 받지 못합니다.

7. 구글 API 서비스 사용자 데이터 정책

Utube Auto 가 구글 API 로 받은 정보를 쓰고 다른 앱으로 옮기는 일은, 제한적 사용(Limited Use) 요구사항을 포함한 Google API Services User Data Policy를 따릅니다.

8. 문의

이 앱의 구글 로그인 동의 화면에 적힌 지원 이메일로 문의할 수 있습니다.

English summary. Utube Auto is a personal Windows desktop application used by a single operator for their own YouTube channels. It uses the youtube.force-ssl scope to upload and schedule the operator's videos, post the operator's first comment, and moderate comments by the operator's rules, and the yt-analytics.readonly scope to read the operator's channel analytics. Data is stored only on the operator's own computer (tokens are encrypted with the Windows user account's protection); there is no server for this app. Google user data is never sold, used for advertising, or transferred to others, except that channel statistics and comment text are sent to the AI tool the operator uses with their own account (Anthropic Claude) solely to analyze performance and plan the next videos. Access can be revoked at any time at Google Account permissions. Utube Auto's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. For questions, use the support email shown on this app's Google consent screen.
